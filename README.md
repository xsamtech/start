## About START

L’initiative START (Science Technology and Agricultural Resource Transformation) est une plateforme en ligne permettant la commercialisation nationale et internationale des produits agricoles de la République démocratique du Congo. Cette plateforme permettra de mettre en relation les petits, moyens et grands exploitants agricoles avec les commerçants et les entreprises, tout en facilitant les négociations et les échanges financiers.
